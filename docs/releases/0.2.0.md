### Play and presentation

- North American NTSC disc support, including regional screen layout, timing, films and text, alongside the existing European PAL release.
- Local split-screen play with independent controllers, per-player HUDs and weapons, working multiplayer rules and successive Versus rounds.
- Reconstructed loading screens, improved front-end menus, mission tallies and end-of-match displays.
- Visible particles, debris, energy-hit effects and BFG beams; corrected projectile shapes, camera projection and lighting.
- Secret chimes, rotating-hatch motors, weapon sounds and fixes for overlapping quad-damage audio.

### Gameplay and saves

- Creature patrol routes and pursuit, solid bodies, corrected melee and shotgun attacks, knockback, BFG beam damage and breakable surfaces.
- Level-start scripts, repeating timers, rotating hatches, scripted explosive groups and scene collision now follow more of the original game's behavior.
- Saves retain live weapon animation and pending shots, projectile effects, timer deadlines, shared random state, creature AI, difficulty, rotators and visited-map script history. Older saves use compatibility defaults for state they did not record.
- Timer rearming consumes the shared random stream and respects the original strict deadline comparison, including timers with zero random range.

### Tools and validation

- Expanded disc inspection, executable-symbol tools and runtime reports.
- This release's gameplay changes passed 40 local tests, 211 PAL headless cases and focused AddressSanitizer checks. Weapon save/restore checks compare framebuffers and subsequent simulation state.
- Release archives are built and tested on Windows x64, Linux x64 and macOS Apple silicon, and include SHA-256 checksums.

### Known limitations

This remains a work in progress. Automatic target selection for weapon pitch is still unimplemented; the pitch-easing code currently receives zero. Further reconstruction gaps and deliberate approximations are recorded in `docs/openquestions.md`, included in each archive.
